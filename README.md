# THWS Adventskalender 2026

A digital advent calendar for THWS students with daily interactive content (videos, images, mini-games). Built with React (frontend), Node.js/Express (backend), and MySQL (database). Embedded into the THWS TYPO3 website.

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React |
| Backend | Node.js / Express |
| Database | MySQL |
| CMS Integration | TYPO3 |
